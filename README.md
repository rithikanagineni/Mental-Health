# MindWellness - Mental Health Awareness Website

A modern, compassionate, and user-friendly mental health platform designed to provide support, resources, and information for individuals seeking emotional wellness.

---

## 🌟 Project Overview

**MindWellness** is a single-page responsive website created as part of **Task 3** for the InAmigos Foundation Internship. 

The website aims to reduce the stigma around mental health, provide valuable information, and offer clear pathways for people to seek professional help. It features a calming design with easy navigation, real resources, and strong calls-to-action.

---

## ✨ Features

- Clean and calming modern design
- Fully responsive (works perfectly on mobile, tablet, and desktop)
- Interactive navigation with smooth scrolling
- Detailed "Our Services" section
- Comprehensive "Conditions We Treat" page
- Real recovery stories with testimonials
- Expanded FAQ section with helpful answers
- Functional contact/appointment form
- Direct links to trusted mental health resources
- Professional footer with quick links and social icons

---

## 🎯 Purpose

This website was built to:
- Raise awareness about mental health importance
- Provide reliable information and resources
- Encourage people to seek professional help without fear or shame
- Showcase a professional web development project for the InAmigos Foundation internship

---

## 🛠 Technologies Used

- HTML5
- CSS3 (Custom CSS - No frameworks)
- Google Fonts (Inter)
- Font Awesome Icons
- Responsive Design (Mobile-First)

---

## 🚀 How to Run the Project

1. Download or clone the project folder
2. Make sure both files are in the same folder:
   - `index.html`
   - `style.css`
3. Double-click `index.html` to open it in your browser
4. Or open the folder in VS Code and use **Live Server** extension
